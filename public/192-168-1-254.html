192.168.1.254 Admin Login: AT&T & BT Hub Guide

Direct Answer: How to Access 192.168.1.254

192.168.1.254 is the default gateway IP address for AT&T Fiber gateways (BGW320, BGW210, NVG589) and British Telecom (BT Smart Hub) devices. To log in: browse to http://192.168.1.254. On AT&T equipment, enter the physical Device Access Code found on the barcode label located on the rear of the device.

How to Authenticate with AT&T Device Access Code

Unlike consumer retail routers, AT&T does not permit a generic password. When making changes to Wi-Fi channel settings, enabling IP Passthrough, or port forwarding on 192.168.1.254, you are prompted for a Device Access Code:

  • Inspect the rear or bottom sticker of your BGW320 or BGW210 gateway.
  • Locate the field labeled Device Access Code (or DAC). It is usually a 10-12 character alphanumeric sequence.
  • Note that this is different from your Wi-Fi password. The Access Code is strictly for administrator system access.
