192.168.1.254: Router Admin Login, Default Credentials & Setup Guide

VB
Written & Tested by Vikas Behl 12+ Yrs Exp
Senior Technical Support & Network Engineer
Reviewed by RouterIPHub Technical Lab ✓ Hardware Verified
Last Updated November 2026
192.168.1.254 is not a website, and it is not a normal "admin/admin" router address. It is a private gateway address used mostly by ISP-supplied gateways, notably AT&T, BT, and some Pace, Arris, and Netgear units. It works only while your device is connected to that gateway. Many of these devices use a printed access code instead of a username and password.

Quick Answer

  1. Connect to the gateway by Wi-Fi or Ethernet. Turn off mobile data and any VPN.
  2. Type 192.168.1.254 into the address bar, not the search bar.
  3. Open the setting you want. Enter the access code or password from the device label if asked.
  4. Change the Wi-Fi password and any default admin password.
Fastest action: Connect to your local gateway network, type http://192.168.1.254 into the address bar, and locate the Device Access Code printed on the gateway sticker.

What Is 192.168.1.254?

It is a private IPv4 address in the 192.168.x.x range. Many ISP gateways use it as their default gateway, which is the address your devices use to reach the unit.

Think of it as the control panel of your gateway. It shows connection status and lets you manage Wi-Fi, firewall rules, and, on AT&T Fiber units, IP Passthrough.

It is often confused with 192.168.1.1. They are different addresses, and a device uses only one.

Is 192.168.1.254 Really Your Gateway?

Verify your local default gateway address before troubleshooting access settings:

  • Windows: Open Command Prompt, run ipconfig, and read Default Gateway.
  • Mac: Go to System Settings > Wi-Fi > Details > TCP/IP and read Router.
  • iPhone: Go to Settings > Wi-Fi > tap the i icon and read Router.
  • Android: Go to Wi-Fi > tap your network > Advanced and read Gateway.

If the number differs, use that address instead. Check our comprehensive guide on finding your router IP address.

How to Log In

Windows or Mac

  1. Connect by Wi-Fi or Ethernet.
  2. Open any browser.
  3. Enter http://192.168.1.254 in the address bar.
  4. Choose the setting you want and enter the access code if prompted.

iPhone

  1. Open Settings > Wi-Fi and join the gateway's network.
  2. Open Safari and enter 192.168.1.254.
  3. Enter the access code if prompted.

Android

  1. Open Settings > Wi-Fi and join the gateway's network.
  2. Open Chrome and enter 192.168.1.254.
  3. Enter the access code if prompted.
Pro-tip: The page can load even when your phone says "connected, no internet", because the gateway page is local and does not depend on an active broadband signal.

Default Credentials

Check the label on the gateway first. These are common patterns, not guarantees.

Device Username Password
AT&T BGW320 and BGW210 None needed Device access code on the label
AT&T NVG series None needed Device access code on the label
BT Home Hub admin Printed on the device card or label
Pace and Arris ISP units admin Label or ISP-set password
Other routers admin Varies

The access code is not the same as the Wi-Fi password. Using the Wi-Fi key at the access-code prompt is a common mistake.

First Settings to Change

  1. Wi-Fi name and password: Use at least 12 characters.
  2. Security mode: Choose WPA3 if available, otherwise WPA2-PSK (AES).
  3. Access code or admin password: Change it if the device allows.
  4. Firmware: ISP gateways usually update automatically. Do not interrupt an update.
  5. Remote management: Turn it off unless you need it.
  6. Guest network: Create one for visitors if available.

Change Wi-Fi Name and Password

  1. Open 192.168.1.254.
  2. Go to Home Network > Wi-Fi (AT&T) or Wireless Settings.
  3. Select the band and edit the SSID and password.
  4. Save and reconnect your devices.

You will be disconnected when you change the password over Wi-Fi. That is expected.

IP Passthrough (AT&T)

Use IP Passthrough when you connect your own router and want to avoid Double NAT.

  1. Connect your router's WAN port to a LAN port on the gateway.
  2. Open 192.168.1.254 and go to Firewall > IP Passthrough.
  3. Set Allocation Mode to Passthrough and Passthrough Mode to DHCPS-fixed.
  4. Select your router's WAN MAC address.
  5. Save, then restart both devices.
Warning: Passthrough hands the public IP to your router, so your router's firewall is then your main protection. Keep its firmware updated.

Port Forwarding

  1. Give the target device a fixed IP or a DHCP reservation.
  2. Go to Firewall > NAT/Gaming (AT&T) or Advanced > Port Forwarding.
  3. Add a rule with the device IP, the port, and the protocol.
  4. Save and apply.
Warning: Open only the ports you need. Each forwarded port exposes that device to the internet.

Troubleshooting

192.168.1.254 will not load

Cause: You are on the wrong network, the gateway IP is different, or a VPN is active.

Fix: Disconnect the VPN and mobile data, confirm your gateway IP, and retry.

Access code not accepted

Cause: A typo, or the Wi-Fi password was used instead.

Fix: Re-read the label. Codes are case-sensitive and avoid easily confused characters, so check each one.

Settings missing

Cause: The ISP hides or locks some options.

Fix: Look in the ISP app or contact support, or use your own router behind the gateway.

Double NAT

Cause: Your own router sits behind the gateway, and both are routing.

Fix: Enable IP Passthrough or bridge mode on the gateway.

No internet after changes

Cause: A settings error or an outage.

Fix: Undo the last change, restart the gateway, and check for outage alerts.

Factory Reset

Use this only when you cannot recover access.

  1. Leave the gateway powered on.
  2. Hold the Reset button for 10 to 15 seconds with a paperclip.
  3. Wait several minutes for it to restart.
  4. Reconnect using the Wi-Fi details on the label.
  5. Set it up again.
Warning: A reset erases Wi-Fi settings, IP Passthrough, and port forwards. On ISP gateways it may also require reactivation.

Common Misspellings

  • 192.168.1.254.1 (extra trailing digit)
  • 192.168.l.254 (a lowercase "L" instead of digit "1")
  • 192.168.01.254 (leading zero)
  • 192.168.1.245 (transposed digits)
  • 192.168.254.1 (different subnet IP)
  • 192.168.1.1 or 10.0.0.1 (alternative router gateway subnets)

Frequently Asked Questions (FAQs)

What is 192.168.1.254?

It is a private IPv4 address that many ISP gateways use as their local admin address.

Do I need a username?

Usually not on AT&T gateways. You use the access code on the label. Other devices may use admin.

Is it the same as 192.168.1.1?

No. They are different addresses, and a device uses one or the other.

Can I open it from outside my home?

No. It is private. Avoid exposing the admin page to the internet.

What if I lost the access code?

Check the label and any setup sheet. If the code was changed and lost, factory reset the gateway.

Bottom Line

192.168.1.254 is the local admin address for many ISP gateways, especially AT&T. Connect to the gateway, enter the address in your browser, and use the access code on the label when asked. If it fails, confirm your real gateway IP first.

Fastest diagnostic step: Run ipconfig on Windows, or check Wi-Fi details on your phone, and read the Default Gateway. If it is not 192.168.1.254, use that address instead.
