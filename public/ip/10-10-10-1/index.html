10.10.10.1: Login Admin, Router, Modem & Gateway Setup Guide

VB
Written & Tested by Vikas Behl 12+ Yrs Exp
Senior Technical Support & Network Engineer
Reviewed by RouterIPHub Technical Lab ✓ Hardware Verified
Last Updated November 2026
10.10.10.1 is not a universal router address, and it is not a website. It is a private gateway address that some routers, modems, and ISP-supplied gateways use by default. Others get it because someone changed the LAN IP to avoid a clash. It works only while your device is connected to the network that owns it. If it fails, your real gateway is almost certainly a different address.

Quick Answer

  1. Connect to the router or modem by Wi-Fi or Ethernet. Turn off mobile data and any VPN.
  2. Type 10.10.10.1 into the address bar, not the search bar.
  3. Sign in with the username and password from the device label, or the ones you set.
  4. Change the admin password and Wi-Fi password straight away.
Fastest diagnostic step: Run ipconfig on Windows, or check Wi-Fi details on your phone, and read the Default Gateway. If it is not 10.10.10.1, use that address instead.

What Is 10.10.10.1?

It is a private IPv4 address in the 10.x.x.x range (defined by RFC 1918), which is reserved for local networks and is never routed across the public internet. Devices use it as their default gateway, which is the internal gateway address your computer sends network traffic to when it leaves the local network.

Many network administrators and tech-savvy users see it after a router, modem, or portable travel router has been reconfigured to a custom LAN range. That is common when two networks would otherwise clash—for example, bridging a remote corporate VPN with a standard home network that already uses 192.168.1.1.

Think of it as the control panel of the device that owns the network. The same number on a different network belongs to a completely different physical device.

Find Your Real Gateway

Before attempting to log in, verify that your client device is actually connected to a 10.10.10.x network:

  • Windows: Open Command Prompt, run ipconfig, and read Default Gateway.
  • Mac: Go to System Settings > Wi-Fi > Details > TCP/IP and read Router.
  • iPhone / iPad: Go to Settings > Wi-Fi, tap the (i) info icon, and read Router.
  • Android: Go to Wi-Fi > tap your network > Advanced and read Gateway.

If the gateway number is not 10.10.10.1 (for example, if it displays 192.168.1.1 or 192.168.0.1), use that specific IP address to access your router settings instead.

How to Log In

Windows or Mac

  1. Connect by Wi-Fi or Ethernet.
  2. Open any browser (Chrome, Edge, Safari, Firefox).
  3. Enter http://10.10.10.1 in the address bar.
  4. Sign in with your credentials.

iPhone & iPad

  1. Open Settings > Wi-Fi and join the network.
  2. Open Safari and enter 10.10.10.1 into the address bar.
  3. Sign in with your admin credentials.

Android

  1. Open Settings > Wi-Fi and join the network.
  2. Open Chrome and enter 10.10.10.1 into the address bar.
  3. Sign in with your admin credentials.

The admin page can load even when your phone displays "Connected, no internet", because local router admin communication does not require an active upstream broadband connection.

Default Credentials

Check the physical label on the device first. These are common defaults, not guarantees:

Device type Username Password
Home routers admin admin or password
ISP gateways admin Printed on the label
Business and enterprise routers Varies Set during deployment
Travel and portable routers admin admin, or set at first use
Custom-configured devices Set by the owner Set by the owner

Newer devices often force you to create a personalized password at first login. Always replace any factory default password immediately.

First Settings to Change

  1. Admin password: Make it unique and different from your Wi-Fi password.
  2. Wi-Fi name and password: Use at least 12 characters with mixed casing, digits, and symbols.
  3. Security mode: Choose WPA3 if available, otherwise WPA2-PSK (AES).
  4. Firmware: Check for security updates and install them.
  5. Remote management: Turn it off unless you specifically require WAN management access.
  6. WPS: Disable WPS (Wi-Fi Protected Setup) to prevent brute-force pin attacks.

Router, Modem & Gateway Setup

Router behind a modem

  1. Connect the modem's Ethernet port to the router's WAN port.
  2. Power on the modem first and wait for the broadband line to settle.
  3. Power on the router and connect your computer to it.
  4. Open http://10.10.10.1 and complete the setup wizard.

Modem-router combo or ISP gateway

  1. Connect the incoming broadband line (coax, fiber, or DSL) as your ISP instructs.
  2. Power on and wait several minutes for status lights to turn solid.
  3. Connect via Wi-Fi or Ethernet and open http://10.10.10.1 if that is the gateway address.
  4. Follow the ISP activation steps if the unit asks for provisioning.

Second router as an access point

  1. Connect a LAN port on the main router to a LAN port on the second router.
  2. Turn off the second router's DHCP server to prevent IP collisions.
  3. Give it a fixed IP in the main router's range (e.g. 10.10.10.2).

Change Wi-Fi Name and Password

  1. Log in at http://10.10.10.1.
  2. Open Wireless, Wi-Fi Settings, or WLAN.
  3. Select the 2.4 GHz or 5 GHz band.
  4. Enter a new SSID and password.
  5. Choose WPA2 or WPA3, then save.
  6. Reconnect your devices.

Change the LAN IP

You may want to change 10.10.10.1 to avoid a clash with a corporate VPN or another cascaded network:

  1. Log in and open LAN, Network, or Local IP settings.
  2. Change the router IP, for example to 192.168.50.1.
  3. Update the DHCP leasing pool range to match the new subnet (e.g., 192.168.50.100–200).
  4. Click Save, then reconnect your device and use the new address.
Warning: After the change, you must use the new address to log in. Note it down first before applying changes.

Port Forwarding

  1. Give the target device a fixed IP or a DHCP reservation in the client table.
  2. Go to Advanced > Port Forwarding, Virtual Server, or NAT.
  3. Add a rule with the device IP, the internal/external port, and protocol (TCP, UDP, or Both).
  4. Save and apply settings.
Warning: Open only the specific ports you need. Each forwarded port exposes that device directly to incoming internet traffic.

Troubleshooting

1. 10.10.10.1 will not load

Cause: You are on the wrong network, your gateway IP is different, or a VPN is intercepting local traffic.

Fix: Disconnect any active VPN and mobile data, confirm your gateway IP via ipconfig, and retry.

2. Password not accepted

Cause: The administrator password was customized, or the label shows the Wi-Fi key rather than the admin password.

Fix: Look for a separate admin password on the device label. If there is none or it fails, reset the device.

3. IP conflict

Cause: Two devices on the same subnet are assigned 10.10.10.1 simultaneously.

Fix: Change one device's IP address, and keep all static IP addresses strictly outside the DHCP pool range.

4. Double NAT

Cause: Your private router sits behind an ISP gateway, and both units are actively performing NAT routing.

Fix: Enable Bridge Mode or IP Passthrough on the modem gateway, or configure your second router in pure Access Point mode.

5. No internet after setup

Cause: Loose cable, ISP service outage, or incorrect WAN connection type (DHCP, PPPoE, or Static IP).

Fix: Inspect Ethernet cables, power-cycle the modem and router in sequence, and confirm your WAN configuration with your broadband provider.

Factory Reset

Use this recovery procedure only when you cannot recover administrator access:

  1. Leave the device powered on.
  2. Hold the recessed Reset button for 10 to 15 seconds with a paperclip.
  3. Wait several minutes for the unit to restart and stabilize its LEDs.
  4. Log in with the default credentials on the label. The gateway address may revert to factory default, so check the label.
  5. Set up the network configuration again.
Warning: A reset completely erases Wi-Fi settings, custom LAN IPs, and port forwards. It may also erase ISP credentials, so note them first.

Common Misspellings

If you get browser search errors, verify you haven't entered one of these common syntax typos:

  • 10.10.10.1.1 — An invalid five-octet IP address.
  • 10.10.10.l — Typing a lowercase letter l instead of the digit 1.
  • 10.10.1.1 — A different Class A subnet gateway.
  • 10.1.10.1 — A transposed subnet octet.
  • 10.0.0.1 or 10.1.1.1 — Different default gateway addresses (10.0.0.1 guide).
  • 192.168.1.1 or 192.168.0.1 — Standard Class C router gateways (192.168.1.1 guide).

Frequently Asked Questions

What is 10.10.10.1?

It is a private IPv4 address that some routers, modems, and gateways use as their local admin address.

Is it my router's IP?

Only if your default gateway shows 10.10.10.1. Check it first using ipconfig or network settings.

Can I open it from outside my home?

No. It is private. Remote access needs a remote-management feature or a VPN, and you should avoid exposing the admin page to the internet.

Why would someone use 10.10.10.1?

Some manufacturers use it by default, and some people choose it to avoid clashes with VPNs or other networks.

What if I forgot the admin password?

Check the label and any setup sheet. If those fail, factory reset the device.

Bottom Line

10.10.10.1 is the local admin address for some routers, modems, and gateways, and a common choice for custom networks. Connect to the device, enter the address in your browser, and sign in with your credentials. If it fails, confirm your real gateway IP first.

Fastest diagnostic step: Run ipconfig on Windows, or check Wi-Fi details on your phone, and read the Default Gateway. If it is not 10.10.10.1, use that address instead.
