192.168.128.1 — Router Admin Login, Default Credentials & Setup Guide

192.168.128.1 is a private IPv4 gateway address. ZTE mobile hotspots, including the Sprint-branded MF975S, use it as their admin page. Connect to the device, open http://192.168.128.1 in a browser, and sign in with the credentials on the label. On the MF975S, the commonly listed login is a blank username with the password password.

Quick Reference

Specification Details
Login URL http://192.168.128.1
Primary Devices ZTE Mobile Hotspots (MF975S, Sprint MiFi), Franklin Wireless, Cisco Meraki Go (GX20, GX50)
Default Username (blank) or admin
Default Password password or admin (check device label)
Address Block RFC 1918 Private IPv4 (Class C 192.168.0.0/16)
Subnet Mask 255.255.255.0 (/24)
Usable DHCP Range 192.168.128.2 – 192.168.128.254 (253 client hosts)

What is 192.168.128.1?

192.168.128.1 is a private address inside the 192.168.0.0/16 range, which RFC 1918 reserves for local networks. No regional internet registry allocates it to anyone, and the public internet never routes it. Your router answers on it only from inside your own network.

Millions of networks reuse this exact address. Two homes can both have a router at 192.168.128.1 without any conflict, because neither one is visible from outside.

The address is far less common than 192.168.1.1 or 192.168.0.1. Three device families are tied to it:

  • ZTE hotspots. The ZTE MF975S Sprint hotspot and similar MiFi units use it as the admin gateway.
  • Franklin Wireless devices. Some hotspot and modem listings show it for this brand.
  • Cisco Meraki Go gateways. The GX20 and GX50 cloud-managed gateways default to the 192.168.128.0/24 subnet, with usable addresses from .2 to .254.

Other lists add Comtrend and Aztech routers, but those claims are thinner. Treat any brand list as a starting point and confirm against your own device.

How to log in at 192.168.128.1

Login takes about two minutes. Your phone or laptop must be on the device's own network, either over Wi-Fi or by cable.

  1. Connect to the router or hotspot network. Join via Wi-Fi or USB tethering.
  2. Open a browser and type http://192.168.128.1 in the address bar. Do not use the search box.
  3. Wait for the sign-in page, then check that the product name matches your device.
  4. Enter the username and password from the label or manual.
  5. Click Login to open the dashboard.

Some devices accept https:// as well. Try it if the plain address refuses to load.

Steps by Platform

Windows / Mac PC

Connect to the hotspot Wi-Fi or via USB tethering, open Chrome, Safari, or Edge, and enter http://192.168.128.1 in the address bar.

iPhone / iPad

Open Settings > Cellular and turn off Cellular Data. Join the hotspot Wi-Fi, open Safari, and navigate to 192.168.128.1.

Android Phone

Disable Mobile Data from the quick toggles. Connect to the hotspot Wi-Fi SSID, launch Chrome, and navigate to http://192.168.128.1.

Default username and password

The label on your device overrides every list below. Defaults vary by brand and firmware, and carriers sometimes change them.

Device Username Password
ZTE MF975S (Sprint hotspot) (blank) password
ZTE hotspots, other models admin admin
Generic router at this IP admin admin or password
Cisco Meraki Go GX20 / GX50 None Managed in the Meraki Go app
Zyxel (other models) admin 1234

Leave the username field empty when the table shows blank. For the Meraki Go gateways, there is no local login to guess. Settings live in the Meraki Go mobile app and cloud dashboard, so the browser page may not offer a password prompt at all.

One public database reports admin / admin as the most frequent pair for this address, at about 26 percent of entries. Take that figure as a rough guide only. It comes from an unverified aggregate.

Important Credential Distinction: Your Wi-Fi password and your admin password are separate. The first lets devices join. The second opens the settings page.

Fix: 192.168.128.1 won't open

A wrong gateway causes most failures. Follow the steps in order:

  • Check the real gateway. On Windows, run ipconfig and read the Default Gateway line. On a Mac, open System Settings, Network, Details, TCP/IP, and read the Router field. If it shows another address, use that one.
  • Turn off mobile data and VPN. Both can send the request outside your local network.
  • Retype the address. Four numbers and three dots. 192.168.138.1 and 192.168.128.1 are easy to confuse.
  • Switch browsers. A private window skips cached redirects and extensions.
  • Move closer or use a cable. Hotspots drop connections at the edge of range.
  • Restart the device. Power it off for 30 seconds, then retry.

If you own a Meraki Go gateway, stop here and use the app. The local page is not the main control surface. Hotspot users on a US carrier should also know that some carriers lock parts of the menu, so a missing setting is not always a fault.

When the page loads but your password fails, try a factory reset. The steps are below.

First-time setup checklist

Four changes protect most small networks. Make them before anything else.

  1. Replace the admin password. Use a unique passphrase of 14 or more characters.
  2. Rename the Wi-Fi and set a strong key. Choose WPA2 or WPA3. Avoid WEP and open networks.
  3. Update the firmware. Check the Update or Maintenance menu. On hotspots, the carrier may push updates for you.
  4. Disable remote management. Leave it off unless you have a specific reason to reach the admin page from outside.

Next, check the connection type. Cable and fiber lines in the US usually use DHCP. DSL lines often use PPPoE with the provider's account name. On a hotspot, the SIM and APN handle this, and you rarely need to touch it.

You can also change the LAN subnet. A work VPN that uses the same 192.168.128.x range will clash with your home network, and the VPN will fail without a clear error. Moving your router to another private range fixes it. Reconnect at the new address after you save.

Reset to factory settings

A reset restores the default IP and credentials and wipes every custom setting. Use it when you can no longer recover the admin password.

  1. Keep the device powered on.
  2. Find the Reset pinhole. On many hotspots it sits under the battery cover or on the side.
  3. Press and hold it with a paperclip for about 10 seconds.
  4. Wait up to two minutes while the device reboots.
  5. Log in at 192.168.128.1 with the label credentials.

Note your Wi-Fi name and any custom settings first, because they vanish. If a Meraki Go gateway is the problem, a local reset may not remove it from your cloud account. Release it in the Meraki Go app as well.

If a carrier supplied the unit, call them. They can confirm the current default password or replace the device.

Is it safe to keep default credentials?

No. Default usernames and passwords for this address are published on many public sites. Anyone on your network can try admin / admin in seconds.

Change the admin login on day one. Then check the connected-devices list each month. If a name looks unfamiliar, change the Wi-Fi password straight away.

Frequently Asked Questions (FAQ)

Is 192.168.128.1 a public IP address?

No. It sits inside the private 192.168.0.0/16 block, and the internet does not route it.

Which devices use 192.168.128.1?

ZTE hotspots such as the Sprint MF975S, some Franklin Wireless units, and Cisco Meraki Go gateways. Check your label.

What is the default password?

For the ZTE MF975S, a blank username and the password password are the commonly listed pair. Other devices often use admin / admin.

Why does a Meraki Go gateway have no password?

Meraki Go manages it through the cloud app, so local credentials are not the primary method.

Can I open it from my phone?

Yes. Join the device's Wi-Fi, switch off mobile data, and open the address in a browser.
