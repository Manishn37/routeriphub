192.168.1.2: Router Login, Default Admin Credentials & Gateway Setup

VB
Written & Tested by Vikas Behl 12+ Yrs Exp
Senior Technical Support & Network Engineer
Reviewed by RouterIPHub Technical Lab ✓ Hardware Verified
Last Updated November 2026
192.168.1.2 is usually not your main router. On most home networks the router sits at 192.168.1.1, and 192.168.1.2 is the first address it hands out to a device. That device might be a second router, a mesh node, an access point, a range extender, a printer, a camera, or a NAS. A few routers and modems do ship with 192.168.1.2 as their own admin address, but this is the exception.

Quick Answer

  1. Connect to the network by Wi-Fi or Ethernet. Turn off mobile data and any VPN.
  2. Type 192.168.1.2 into the address bar, not the search bar.
  3. Look at what loads. A login page shows which device owns the address.
  4. If nothing loads, find your real gateway IP before trying anything else.
Fastest action: Check your device's default gateway first. If your primary gateway is 192.168.1.1, open that address to inspect your DHCP client list and identify exactly what hardware is assigned to 192.168.1.2.

What Is 192.168.1.2?

It is a private IPv4 address in the 192.168.1.x range. Routers hand out addresses in this range automatically through DHCP (Dynamic Host Configuration Protocol), and the lowest numerical host addresses in the DHCP pool are often given out first.

That is why the same address can belong to completely different devices on different home networks, or even to different devices on one network after a reboot. Think of it as a house number on your street: the number is fixed, but who lives there can change.

Find Your Real Gateway

Before trying to configure 192.168.1.2, verify the true default gateway address of your active network connection:

  • Windows: Open Command Prompt, run ipconfig, and read Default Gateway.
  • Mac: Go to System Settings > Wi-Fi > Details > TCP/IP and read Router.
  • iPhone / iPad: Go to Settings > Wi-Fi, tap the (i) info icon next to your network, and read Router.
  • Android: Go to Settings > Network & internet > Wi-Fi, tap your network gear icon, expand Advanced, and read Gateway.

If the gateway is 192.168.1.1, that is your primary main router. In that case, 192.168.1.2 belongs to another connected device on your network, and it is worth finding out which one.

Find Out Who Owns 192.168.1.2

  1. Log in to your main router, usually at 192.168.1.1.
  2. Open Connected Devices, DHCP Clients, or Device List.
  3. Look for 192.168.1.2 and read its device name and MAC address.
  4. Decide whether it is something you recognize.

You can also run arp -a in Windows Command Prompt or macOS/Linux Terminal and look for the 192.168.1.2 entry to inspect its physical MAC address. If you do not recognize the device, change your Wi-Fi password and review unauthorized connections.

How to Log In

Windows or Mac

  1. Connect by Wi-Fi or Ethernet.
  2. Open any browser (Chrome, Edge, Safari, Firefox).
  3. Enter http://192.168.1.2 in the address bar.
  4. Sign in with the device's credentials.

iPhone & iPad

  1. Open Settings > Wi-Fi and join the local network.
  2. Open Safari and enter 192.168.1.2 into the address bar.
  3. Sign in with the admin credentials.

Android

  1. Open Settings > Wi-Fi and join the local network.
  2. Open Chrome and enter 192.168.1.2 into the address bar.
  3. Sign in with the admin credentials.
Extender & AP Note: If the login page belongs to a second router or extender, you must be connected to the network it serves. Some extenders also broadcast their own dedicated temporary setup network (e.g., NETGEAR_EXT or TP-Link_Extender), so join that network first if you cannot reach 192.168.1.2.

Default Credentials

Check the physical label on the device first. These are common manufacturer defaults, not guarantees:

Device type Username Password
Routers and modems that use this IP admin admin, password, or blank
Range extenders and access points admin admin, or none until you set one
IP cameras admin Often set during first-time setup
Network printers Often none Varies, usually set by the owner
NAS devices admin Set during initial installation setup

Newer devices often force you to create a secure password on first use. Always replace any factory default password with a unique, strong passphrase.

Gateway Setup Basics

If 192.168.1.2 is a secondary router, repeater, or access point you control, follow these setup steps:

  1. Plug it in and wait a few minutes for it to boot up completely.
  2. Connect to its network via Ethernet or default Wi-Fi, then open http://192.168.1.2.
  3. Complete the initial configuration setup wizard.
  4. Set a new admin password and Wi-Fi network name (SSID) and passphrase.
  5. Check for and apply the latest firmware updates.

Using it as a second router

  1. Connect it to the main router with a high-grade Cat6 Ethernet cable.
  2. Use the main router's LAN port. Plugging into the second router's WAN port runs it as a separate subnet network, which can cause Double NAT issues for online gaming and port forwarding.
  3. For a simple, seamless access point, plug into a LAN port on the second router and turn off its DHCP server.
  4. Give it a fixed static IP address outside the main router's dynamic DHCP allocation range (for example, if the primary router hands out 192.168.1.100–192.168.1.250, assign 192.168.1.2 statically).

Change Wi-Fi Name and Password

  1. Log in at http://192.168.1.2 using your web browser.
  2. Open Wireless or Wi-Fi Settings from the navigation menu.
  3. Select the 2.4 GHz or 5 GHz band (or unified Smart Connect SSID).
  4. Enter your preferred new Wi-Fi name (SSID) and strong password.
  5. Choose WPA2-PSK (AES) or WPA3-Personal encryption, then click Save / Apply.
  6. Reconnect all your phones, tablets, and smart home devices to the new network credentials.

Troubleshooting

1. 192.168.1.2 will not load

Cause: No device currently has this address, or you are on a different network subnet.

Fix: Check your primary router's connected device list, confirm your gateway IP via ipconfig, and disconnect any active VPN or proxy.

2. A different device appears

Cause: The main router's DHCP server assigned the 192.168.1.2 address to another device (printer, TV, or phone) following a reboot.

Fix: Identify the device from your router's DHCP table by its MAC address, and configure a static DHCP IP reservation so its address never changes.

3. IP conflict

Cause: Two devices are attempting to use 192.168.1.2 simultaneously, often when a second router has a hardcoded static IP while the primary router leases that same address to another host.

Fix: Change one device's IP address, and always assign static IP configurations outside the active DHCP leasing range.

4. Extender or second router unreachable

Cause: The secondary unit may be booted in unconfigured setup mode, on an isolated VLAN, or using a fallback address.

Fix: Connect your computer directly to the unit using an Ethernet patch cable, or join its dedicated setup Wi-Fi network, then retry navigating to http://192.168.1.2.

5. Password not accepted

Cause: The default administrator password was customized previously or entered incorrectly.

Fix: Double-check the device label sticker for a custom serial or access key. If credentials remain unrecoverable, perform a hardware factory reset.

Factory Reset

Use this recovery procedure only when you cannot regain access to a secondary hardware unit you own:

  1. Ensure the device is powered ON.
  2. Locate the recessed Reset pinhole button on the rear or bottom casing.
  3. Press and hold the button for 10 to 15 seconds using a straightened paperclip or SIM ejector tool.
  4. Release the button and wait 2 to 3 minutes for all status LEDs to cycle and stabilize.
  5. Log in using the factory default credentials printed on the hardware label and reconfigure the unit.
Warning: A reset completely erases all custom Wi-Fi network names, passwords, DHCP reservations, and port forwarding rules. On a primary router, it can also erase broadband ISP PPPoE credentials. Do not reset your main router just to regain access to a secondary device.

Common Misspellings

If you experience DNS search errors or browser search redirection, verify that you haven't entered one of these common syntax typos:

  • 192.168.1.2.1 — An invalid five-octet address string.
  • 192.168.l.2 — Replaces the number 1 with a lowercase letter l.
  • 192.168.01.2 — Includes an extraneous leading zero rejected by browsers.
  • 192.168.2.1 — A completely separate Class C subnet gateway (192.168.2.1 guide).
  • 192.168.1.20 or 192.168.1.22 — Host addresses assigned to different client devices.

Frequently Asked Questions

What is 192.168.1.2?

It is a private IPv4 address, usually assigned to a device on a 192.168.1.x network. Occasionally it is a router's own address.

Is it my router's IP?

Usually not. Check your default gateway to be sure. Most main routers sit at 192.168.1.1.

Can I open it from outside my home?

No. It is private. Avoid exposing admin pages to the internet.

Is it safe?

Yes, from inside your own network. The risk comes from default passwords and outdated firmware.

What if I forgot the password?

Check the label and any setup sheet. If those fail, factory reset that device.

Bottom Line

192.168.1.2 is a private address that most often belongs to a secondary device, not your main router. Check your default gateway first, then use your router's device list to see who holds 192.168.1.2. If it is a device you own, log in with the credentials on its label.

Fastest diagnostic step: Run ipconfig on Windows, or check Wi-Fi details on your phone. If the Default Gateway is 192.168.1.1, open that address and look up 192.168.1.2 in the connected-device list.
