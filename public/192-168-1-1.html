192.168.1.1 Admin Login, Password & Gateway Guide

Direct Answer: How to Access 192.168.1.1

192.168.1.1 is the private default gateway IP for Netgear, ASUS, Linksys, Cisco, and Verizon routers. To log in: connect to your router's network, open a browser, navigate to http://192.168.1.1, and log in with username admin and password admin (ASUS/Linksys) or password (Netgear).

Step-by-Step: How to Log Into 192.168.1.1

  1. Connect to your local network: Connect your device via Wi-Fi or with a direct RJ45 Ethernet cable into one of the router's LAN ports (numbered 1 through 4).
  2. Open your web browser: Launch Google Chrome, Apple Safari, Mozilla Firefox, or Microsoft Edge.
  3. Type http://192.168.1.1: Type http://192.168.1.1 directly into the browser URL address bar (not the Google search bar) and press Enter.
  4. Enter default username and password: When the authentication prompt appears, enter the manufacturer default credentials (e.g., admin / password for Netgear).
  5. Save new credentials: For cybersecurity best practices, immediately change the default admin password to a unique, complex passphrase.

Troubleshooting: Why 192.168.1.1 Won't Open

If visiting 192.168.1.1 returns a "This site can't be reached", "Connection timed out", or "ERR_CONNECTION_REFUSED" error, follow these diagnostic fixes:

1. Check for Common Typos

Typing IP addresses manually frequently leads to character errors. Ensure you are not entering:

  • 192.168.l.l — Typing lowercase letter l instead of number 1.
  • 192.168.1.l — Mixing letters and numbers.
  • 192.168.1.1.com or www.192.168.1.1 — IP addresses do not use web suffixes or 'www'.
  • http://192.168.11 — Missing dot separators.

2. Disable VPN and Proxy Services

If you run NordVPN, ExpressVPN, Surfshark, or a corporate corporate VPN client, all outgoing traffic is encrypted and tunneled through external servers. This breaks local LAN subnet routing. Disconnect your VPN and reload the page.

3. Confirm Your Actual Gateway IP

Your router may not be using 192.168.1.1. Many ISPs and brands default to 192.168.0.1 (TP-Link) or 10.0.0.1 (Xfinity).

  • On Windows: Open Command Prompt and run ipconfig. Look for the Default Gateway line.
  • On Mac: Open Terminal and execute route -n get default | grep gateway.

For complete instructions across all operating systems, see our Find Router IP Guide.

4. Perform a 30-Second Factory Reset

If previous owners customized the admin login password and you cannot sign in:

  • Ensure the router is plugged in and powered on.
  • Locate the small recessed Reset pinhole on the rear or underside of the unit.
  • Insert an unfolded paperclip or SIM ejector tool and hold the button for 15 to 30 seconds until the LED indicators blink simultaneously.
  • Allow 2 minutes for the router to reboot into factory default settings. The default credentials from our table will now work.
