IPv4 CIDR Subnet Calculator

Calculate network ID, broadcast address, CIDR prefix (/8 to /30), usable host range, and binary subnet masks in real time.

How to Use the IPv4 Subnet Calculator

This client-side Subnet Calculator allows network engineers, system administrators, and home lab enthusiasts to analyze any IPv4 address and CIDR prefix length without sending data to an external server. Follow these simple steps:

  1. Enter your IP Address: Type the host IP address or gateway address (e.g., 192.168.1.1 or 10.0.0.1) into the input field.
  2. Select your CIDR Prefix / Subnet Mask: Choose the prefix length from the dropdown menu, ranging from /8 (Class A) to /30 (Point-to-Point links). The standard home subnet is /24 (255.255.255.0).
  3. Inspect Calculated Parameters: The tool dynamically calculates the Network ID, Broadcast Address, Total IP count, Usable Host Range, and Wildcard Mask in real time.

Understanding CIDR Notation & Subnetting Fundamentals

Classless Inter-Domain Routing (CIDR, defined in RFC 4632) replaced legacy classful networking (Class A, B, and C) to allocate IP address blocks with much greater granularity. In CIDR notation, an IP address is appended with a forward slash followed by a number indicating the number of contiguous leading bits assigned to the network prefix.

An IPv4 address consists of 32 binary bits divided into four 8-bit octets. For example, in a /24 subnet:

  • Network Bits: 24 bits are dedicated to identifying the network (e.g. 11111111.11111111.11111111.00000000 = 255.255.255.0).
  • Host Bits: 8 bits remain for assigning to client hosts (32 − 24 = 8 bits).
  • Total Addresses: 28 = 256 addresses.
  • Usable Hosts: 256 − 2 = 254 hosts (the first address is reserved as the Network ID and the last address is reserved as the Broadcast Address).

Frequently Asked Questions About Subnetting

Why can't I use the first and last IP addresses in a subnet?

In IPv4 networking, the very first address represents the entire network block itself (the Network ID), used by routers to direct traffic. The last address with all host bits set to 1 is the directed broadcast address, used to broadcast packets to every device on that specific subnet simultaneously. Consequently, assigning either address to a host device creates addressing conflicts.

What is the default subnet mask for 192.168.1.1?

The standard subnet mask for 192.168.1.1 is 255.255.255.0 (corresponding to a /24 prefix). This allows your router to assign DHCP leases to devices in the range 192.168.1.2 through 192.168.1.254.

What is a Wildcard Mask and where is it used?

A wildcard mask is the bitwise inverse of the subnet mask. For instance, if the subnet mask is 255.255.255.0, its wildcard mask is 0.0.0.255. Wildcard masks are predominantly used in Cisco IOS Access Control Lists (ACLs) and routing protocols like OSPF and EIGRP to match IP address ranges.
