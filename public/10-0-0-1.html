10.0.0.1 Admin Login & Xfinity Setup Guide

Direct Answer: How to Access 10.0.0.1

10.0.0.1 is the Class A default gateway IP address primarily used by Comcast / Xfinity on their xFi Wireless Gateways (XB3, XB6, XB7, and XB8) and Apple AirPort devices. Access the login console at http://10.0.0.1 using the default username admin and default password password.

How to Log Into 10.0.0.1 on Xfinity Gateways

  1. Connect your device to your home Xfinity Wi-Fi network or plug in an Ethernet cable.
  2. Open any browser and type http://10.0.0.1 into the address bar.
  3. In the username field, type admin. In the password field, type password.
  4. If prompted, enter a new personal administrative password to secure your gateway.

Important Note on the Xfinity App

On recent Xfinity firmware releases (particularly XB7 and XB8 gateways), Comcast has relocated some advanced Wi-Fi settings (such as SSID name changes, port forwarding, and parental controls) into the mobile Xfinity App. If the 10.0.0.1 web panel shows certain configuration fields greyed out, use the official Xfinity iOS or Android mobile application to adjust those settings.
