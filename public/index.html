Quick Answer: Default Router Gateway Directory

The default IP address for most routers is 192.168.1.1 (Netgear, ASUS, Linksys) or 192.168.0.1 (TP-Link, D-Link). Other common gateway IPs include 10.0.0.1 (Xfinity), 192.168.1.254 (AT&T/BT), 192.168.2.1 (Belkin), 192.168.8.1 (Huawei/GL.iNet), 192.168.31.1 (Xiaomi), 192.168.88.1 (MikroTik), and 192.168.12.1 (T-Mobile 5G).

How to Log Into Any Wireless Router (4 Simple Steps)

Follow this standardized procedure to connect and authenticate into your home Wi-Fi, mesh system, or office network gateway.

1

Connect to Network

Connect your device via Wi-Fi or plug an Ethernet cable into LAN ports 1 through 4. If Wi-Fi is unresponsive, Ethernet provides direct access.

2

Open Gateway IP

Open any web browser and enter your router's IP directly into the top address bar (e.g. 192.168.1.1, 192.168.0.1, or 10.0.0.1).

3

Enter Credentials

Type the default username (usually admin) and password from our matrix or the physical barcode label on your hardware.

4

Configure Settings

Once inside the dashboard, change the default Wi-Fi password, set a strong admin security key, and check for firmware updates.

Both are private IPv4 addresses reserved under RFC 1918 for local area networks. Manufacturers choose one subnet as the factory default: Netgear and ASUS traditionally use 192.168.1.1, while TP-Link and D-Link default to 192.168.0.1. Both fulfill the exact same gateway role.
If the default credentials fail, the password was likely customized during initial setup or assigned uniquely by your ISP. Check the sticker on the underside of your router for a "Device Access Code" or "Admin Password". If forgotten, you can hold the recessed Reset button on the back of the router for 10-15 seconds using a paperclip to restore factory settings.
Specialized hardware uses dedicated subnets: 192.168.8.1 is the standard for 4G/5G mobile routers (Huawei, GL.iNet), and 192.168.12.1 is used by T-Mobile 5G Home Internet. This prevents IP collisions with upstream networks.
