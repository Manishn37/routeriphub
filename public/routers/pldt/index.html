PLDT Default Login — Username, Password and IP Address

The standard PLDT router login is username admin, password 1234, and IP address 192.168.1.1. These are the default details in PLDT’s general Wi-Fi management instructions, but they will not work if your administrator credentials have already been changed.[pldthome]

Start with the standard login below. If your router uses different credentials, follow the instructions supplied for your exact model rather than trying random administrator passwords.

Quick Answer

Connect to your PLDT home network, open https://192.168.1.1, and enter:

Login detail Default value
Router IP address 192.168.1.1
Login address https://192.168.1.1
Username admin
Password 1234

These are the standard credentials in PLDT’s general instructions—not a guarantee that every PLDT-supplied device or previously configured router still uses them.[pldthome]

How to Log In to Your PLDT Router

Step 1

Connect to your PLDT network

Connect your phone or computer to the router you want to manage. Use its Wi-Fi network or a direct Ethernet connection. If you have a separate router or repeater, make sure you are accessing the intended device rather than another management page on your network.

Step 2

Open the router address

Enter this directly into your browser’s address bar:

https://192.168.1.1

Do not enter it into a search engine. You want the local router interface, not a website listing router passwords.

Step 3

Enter the default credentials

Use Username: admin and Password: 1234. If you previously changed the administrator login, enter your current credentials instead.

Step 4

Complete any first-login setup

On first use, the dashboard may prompt you to change the default administrator credentials under Account Management. PLDT’s instructions also describe fields for updating the Wi-Fi name and password during initial configuration.

Step 5

Open the settings you need

Once signed in, select the relevant settings section. Menu names can vary by router model and firmware.

Which PLDT Password Do You Need?

A router administrator password, a Wi-Fi password, and a myHome account password are completely different credentials:

Credential What it does Where you use it
Router administrator password Opens the router’s management dashboard Local router login page
Wi-Fi password Connects devices to your wireless network Phone, computer, or other device’s Wi-Fi settings
myHome account password Opens your PLDT online account myHome account sign-in

PLDT provides separate procedures for router Wi-Fi management and myHome account-password recovery. Resetting your myHome password is not the same as changing the router login.

How to Change Your PLDT Wi-Fi Name

PLDT’s general instructions use this menu path:

  1. Sign in to the router dashboard.
  2. Open Basic.
  3. Select Wireless LAN (WLAN) Settings.
  4. Find SSID Name.
  5. Enter your preferred Wi-Fi name.
  6. Select Apply Changes and Save.

The SSID is the network name your devices see when searching for Wi-Fi. Your router’s exact interface may use slightly different labels.

How to Change Your PLDT Wi-Fi Password

After signing in:

  1. Open Wireless LAN (WLAN) Settings.
  2. Select Security.
  3. Find the Pre-shared Key field.
  4. Enter your new Wi-Fi password.
  5. Apply and save the changes.

Important: Make sure you are editing the wireless-network password, not the administrator-account password.

How to Change the Administrator Login

If the dashboard prompts you to replace the default credentials, open Account Management and complete the required fields.

Keep a record of your new administrator login. Once the default password has been replaced, 1234 is no longer the password to use for that account.

PLDT Login Not Working? Identify the Problem First

What you see What to check
The router page does not open Network connection and management address
The login page opens, but credentials are rejected Current administrator username and password
You can connect to Wi-Fi but cannot sign in Whether you are confusing the Wi-Fi password with the admin password
A repeater login page appears Whether you are managing the intended device
The interface differs from these instructions Your router model and firmware

A page-access problem and a rejected-password problem need different fixes. If the login form appears, you have already reached a management interface; repeatedly changing the address will not correct an invalid password.

1. Check the address carefully

Use: https://192.168.1.1. Avoid typing the lowercase letter l in place of the number 1.

192.168.l.l 192.168.1.l 192.168.1.1.com ✓ https://192.168.1.1

2. Confirm which device you are managing

Do not assume every PLDT-branded networking device uses the same address. For example, the PLDT Prolink Home Repeater guide specifies 192.168.1.253 with username admin and password 1234. Those are repeater instructions, not the standard gateway address.

3. Use your current administrator credentials

The standard admin / 1234 combination will not work after it has been changed. Check your saved credentials or the setup instructions provided for your router. Do not assume a password printed for Wi-Fi access is also the administrator password.

4. Follow model-specific recovery instructions

If you cannot recover the administrator login, use the recovery procedure for your exact router or contact PLDT for assistance. Avoid using a generic reset-button timing from an unrelated model.

Should You Factory Reset the Router?

Do not treat a factory reset as the first fix for a rejected password.

Before proceeding, confirm the recovery instructions for your exact model and whether any service settings will need to be restored. Record the configuration you need to preserve. A reset is different from a normal restart. Only proceed when you understand what your model’s reset procedure changes.

Common PLDT Login Mistakes

  • Assuming admin / 1234 must work after the credentials have been changed.
  • Entering the Wi-Fi password into the administrator login form.
  • Using a myHome account password for the local router dashboard.
  • Following repeater instructions when trying to manage the main router.
  • Typing the IP address into a search engine instead of the browser’s address bar.
  • Resetting the router before checking model-specific recovery instructions.

Frequently Asked Questions (FAQs)

What is the default PLDT router username?

The standard username in PLDT’s general router-login instructions is admin.

What is the default PLDT router password?

The standard password is 1234. Use your current administrator password if you changed it.

What is the default PLDT router IP address?

The standard management address is 192.168.1.1. Open https://192.168.1.1 from a device connected to your home network.

Why does admin / 1234 not work?

The administrator credentials may have been changed, or your device may use different model-specific login details. Check the instructions for your exact router rather than assuming every PLDT device uses the same login.

Is the PLDT Wi-Fi password the same as the administrator password?

Do not assume they are the same. The Wi-Fi password connects devices to the wireless network; the administrator password opens the router’s settings.

Is the myHome password used for router login?

No. Your myHome account login is separate from the local router administrator login.

Do PLDT repeaters use 192.168.1.1?

Not necessarily. The PLDT Prolink Home Repeater guide specifies 192.168.1.253, so use the instructions for the particular repeater.

The Bottom Line

Start with https://192.168.1.1, username admin, and password 1234. If the login page opens but rejects those credentials, check your current administrator password and your router’s model-specific instructions before considering a reset.
