BT (British Telecom) Gateway Login — 192.168.1.254 Admin Access

If you searched 192.168.1.254 expecting your BT Hub’s settings page, you have the right address. The important detail is the password: BT Hubs use an admin password, which is separate from the Wi-Fi password.

Open 192.168.1.254 from a device connected to your BT home network. When prompted, enter the admin password printed on the Hub.

How to Log In to Your BT Hub

1. Connect to the BT Hub

Connect your phone, tablet, or computer to the BT Hub’s Wi-Fi network. For a more reliable connection, use an Ethernet cable between your computer and one of the Hub’s LAN ports.

Do not use mobile data. The Hub Manager is a local interface and must be accessed from the home network.

2. Open the Hub Manager address

Enter this directly into your browser’s address bar:

192.168.1.254 or http://bthomehub.home

Do not enter the address into a search engine. You need the local Hub Manager page, not a web search result.

3. Accept the HTTPS security warning if it appears

If your browser shows a message such as “Your connection is not private,” select Advanced, then choose the option to proceed to 192.168.1.254.

This warning can appear because the Hub uses a self-signed certificate for its local HTTPS page. Only proceed if you entered the address yourself and are connected to your own home network.

Browser What to select
Chrome Advanced → Proceed to 192.168.1.254 (unsafe)
Microsoft Edge Advanced → Continue to 192.168.1.254 (unsafe)
Safari Show Details → Visit this website → Visit Website
Firefox Advanced → Accept the Risk and Continue

4. Enter the admin password

When prompted, enter the Hub admin password.

  • If you have not changed it, use the password on the Hub settings card on the back of the Hub.
  • If you changed it previously, use your current custom admin password.
  • Do not use the Wi-Fi password unless it is the same password you deliberately set for Hub Manager.

5. Open the settings you need

Once signed in, select the section related to your task. BT Hub Manager supports settings such as Wi-Fi network names and passwords, device management, security settings, and advanced Hub configuration.

Change Your BT Wi-Fi Name and Password

To change the wireless network details:

  1. Sign in to the Hub at 192.168.1.254.
  2. Open Advanced Settings.
  3. Select Wireless.
  4. Select Wi-Fi name (SSID) or Wi-Fi password.
  5. Enter your preferred Wi-Fi name and password.
  6. Select Apply or Save.

Changing the Wi-Fi name or password disconnects devices using the old credentials. Reconnect them using the updated details.

Admin Password vs. Wi-Fi Password

The Hub admin password opens the BT Hub’s management interface. The Wi-Fi password connects phones, computers, TVs, and other devices to the wireless network.

Both may appear on the same Hub settings card, so read the field names carefully. The admin password is specifically used to access and change Hub settings.

If your phone is connected to Wi-Fi but the Hub rejects your login, that does not necessarily mean the Wi-Fi password is wrong. Check that you are entering the admin password in the login form.

If 192.168.1.254 Will Not Open

1. Confirm the connection

Make sure your device is connected to the correct BT Hub. If you have a mesh system, extender, powerline adapter, or separate router, you may be connected to a different device.

Use a direct Ethernet connection to the BT Hub when possible. This removes Wi-Fi signal issues from the troubleshooting process.

2. Check the address carefully

Use:

http://192.168.1.254

Avoid incorrect entries such as:

  • 192.168.l.254
  • 192.168.1.254.com
  • 192.168.1.254 router login
  • 192.168.1.254/admin when you only want the main Hub Manager page

Enter the address directly into the browser’s address bar rather than a search engine.

3. Try the alternative address

Use:

http://bthomehub.home

This is an alternative way to reach Hub Manager.

4. Try the secure address

Use:

https://192.168.1.254

If your browser shows a security warning, it may be because the Hub uses a self-signed certificate for its local HTTPS page. Only proceed if you entered the address yourself and are connected to your own home network.

5. Disable VPN or proxy temporarily

A VPN, proxy, or privacy-focused browser setting can interfere with access to a local Hub address. Disconnect the VPN and disable proxy settings, then try again.

6. Try another browser or device

Try Chrome, Firefox, Edge, or Safari. If one browser fails, test the page from another phone, tablet, or computer connected to the same BT network.

7. Restart the Hub

Turn the Hub off, wait about 30 seconds, then turn it back on. Wait for the lights to stabilize, reconnect your device, and try 192.168.1.254 again.

A restart preserves your Hub settings. Do not confuse it with a factory reset.

If the Admin Password Is Rejected

Check the correct password field

Look for the admin password, not the Wi-Fi password. The admin password opens Hub Manager settings; the Wi-Fi password connects devices to the wireless network.

Check the Hub model

The location of the default password depends on the Hub version:

Hub model Default admin password location
BT Smart Hub 2 Hub settings card on the back
BT Smart Hub Hub settings card on the back
BT Home Hub 4 or Hub 5 Hub settings card or label on the base
BT Home Hub 3 Hub settings card or label on the base

Consider whether the password was changed

If you previously changed the admin password, use that custom password. The original password on the settings card will no longer work.

If you cannot remember the changed admin password, check the password-reset guidance for your Hub model. Do not reset the Hub until you understand what settings may be lost.

Why You May Reach a Different Router Page

If you have another router, mesh system, or extender, your device may be connected to a network that uses a different gateway address.

In that case, 192.168.1.254 may not be the address of the device you are trying to manage. Check your device’s gateway address and use that instead.

A Hub Manager page should only be reached from within your local home network.

When to Factory Reset the BT Hub

Do not factory reset the Hub as the first fix.

Before resetting:

  • Confirm you are connected to the BT Hub.
  • Try 192.168.1.254 and bthomehub.home.
  • Disable VPN and proxy settings.
  • Try another browser or device.
  • Restart the Hub.
  • Check the correct admin password.

A factory reset can remove custom Hub settings, including Wi-Fi names, passwords, and the admin password. Record anything you need before resetting, and follow the reset instructions for your exact Hub model.

Common Mistakes

  • Using mobile data instead of connecting to the BT Hub.
  • Assuming the Wi-Fi password is the Hub admin password.
  • Closing the browser when the HTTPS warning appears without checking that it is the local Hub page.
  • Trying 192.168.1.1 when the BT Hub uses 192.168.1.254.
  • Leaving a VPN or proxy enabled.
  • Factory resetting before trying the simpler access fixes.

FAQs

What is the BT Hub Manager address?
The standard address is 192.168.1.254. You can also use http://bthomehub.home.
What is the default BT Hub admin password?
It is printed on the Hub settings card on the back of the Hub, unless you changed it. The location can vary slightly by Hub model.
Is the BT Hub admin password the same as the Wi-Fi password?
No. The admin password opens Hub Manager settings; the Wi-Fi password connects devices to the wireless network.
Can I change my Wi-Fi password from the Hub Manager page?
Yes. Sign in, open Advanced Settings, select Wireless, and update the Wi-Fi name or password before saving.
Why can’t I open 192.168.1.254?
You may not be connected to the BT Hub, or a VPN, proxy, or browser setting may be blocking the local address. Confirm the connection and try the alternative address.
Can I access BT Hub Manager from outside my home?
No. Hub Manager is a local management interface and must be accessed from a device connected to the Hub’s network.
Should I reset my BT Hub if 192.168.1.254 does not work?
Not immediately. First check the connection, try the alternative address, disable VPN or proxy settings, test another browser, and restart the Hub.

The Bottom Line

Open 192.168.1.254 from your BT home network and enter the Hub admin password from the back of the Hub. Do not confuse it with the Wi-Fi password. If the page will not open, disconnect VPN or proxy settings and restart the Hub before considering a reset.
