Telstra (Australia) Gateway Login — 192.168.0.1 Admin Access

If you searched 192.168.0.1 expecting your Telstra gateway’s settings page, you have the right address for many Telstra Smart Modems. The important detail is the password: newer Telstra Smart Modems use the Wi-Fi password printed on the modem label, while some older models use Telstra.

Open http://mymodem or http://192.168.0.1 from a device connected to your Telstra home network. Sign in with admin and the correct password for your modem model.

How to Log In to Your Telstra Gateway

1. Connect to the Telstra home network

Connect your phone, tablet, or computer to the Telstra modem’s Wi-Fi network. For a more reliable connection, use an Ethernet cable between your computer and one of the modem’s LAN ports.

Do not use mobile data. The gateway settings page is a local interface and must be accessed from the home network.

2. Open the management address

Enter one of these directly into your browser’s address bar:

http://mymodem or http://192.168.0.1

Do not enter the address into a search engine. You need the local modem interface, not a web search result.

3. Enter the administrator credentials

Use:

  • Username: admin
  • Password: The password that matches your modem model

For a Gen 4 or Gen 3 Smart Modem, use the Wi-Fi password printed on the bottom label or reusable sticker. For Gen 2 and 1.1 models, use Telstra.

4. Open the settings you need

Once signed in, choose the section related to your task. Common options include Wi-Fi settings, connected devices, security settings, and modem status.

Change Your Telstra Wi-Fi Name and Password

To change the wireless network details:

  1. Sign in to the gateway at http://mymodem or http://192.168.0.1.
  2. Select Wi-Fi Settings.
  3. Enter your preferred Wi-Fi name in Wi-Fi Name (SSID).
  4. Enter your preferred password in Wi-Fi Security Key.
  5. Select Apply to save the changes.

Changing the Wi-Fi name or password disconnects devices using the old credentials. Reconnect them using the updated details.

Admin Password vs. Wi-Fi Password

The administrator password opens the Telstra gateway’s settings page. The Wi-Fi password connects phones, computers, TVs, and other devices to the wireless network.

On Gen 4 and Gen 3 Smart Modems, the default administrator password happens to be the same as the original Wi-Fi password. That does not mean they remain the same after either password is changed.

If you changed the Wi-Fi password but not the administrator password, use the original modem-label password to sign in. If you changed the administrator password, use that custom password instead.

If 192.168.0.1 Will Not Open

1. Confirm the connection

Make sure your device is connected to the Telstra gateway’s network. If you have a mesh system, extender, or separate router, you may be connected to a different device.

Use a direct Ethernet connection to the Telstra modem when possible. This removes Wi-Fi signal problems from the troubleshooting process.

2. Check the address

Enter:

http://192.168.0.1

Avoid incorrect entries such as:

  • 192.168.o.1
  • 192.168.0.l
  • 192.168.0.1.com
  • 192.168.0.1 router login

Enter the address directly into the browser’s address bar rather than a search engine.

3. Try the alternative address

Use:

http://mymodem

This is an alternative address for accessing the modem settings page.

4. Disable VPN or proxy temporarily

A VPN, proxy, or privacy-focused browser setting can interfere with access to a local gateway address. Disconnect the VPN and disable proxy settings, then try again.

5. Try another browser or device

Try Chrome, Firefox, Edge, or Safari. If one browser fails, test the page from another phone, tablet, or computer connected to the same Telstra network.

6. Restart the modem

Turn the modem off, wait about 30 seconds, then turn it back on. Wait for the lights to stabilize, reconnect your device, and try http://mymodem or http://192.168.0.1 again.

A restart preserves your settings. Do not confuse it with a factory reset.

If the Password Is Rejected

Check the modem model

The default password changes by model:

What you have Password to try
Smart Modem Gen 4 Original Wi-Fi password from the modem label or reusable sticker
Smart Modem Gen 3 Original Wi-Fi password from the modem label
Smart Modem Gen 2 Telstra
Smart Modem 1.1 Telstra
Older Gateway Pro telstra

Check whether the password was changed

If you or someone else changed the administrator password, the original label password will no longer work. Use the current custom password instead.

Check the correct password field

Do not automatically enter your current Wi-Fi password. For Gen 4 and Gen 3, the default administrator password is the original Wi-Fi password printed on the modem label—not necessarily the password currently used to connect devices.

Older Telstra Gateway Pro Login

The Telstra Gateway Pro uses a different management address and default password:

Setting Value
Management address 192.168.15.1
Username admin
Default password telstra

This is not the same as the newer Smart Modem address 192.168.0.1. Use the instructions for your exact gateway model.

When to Factory Reset the Modem

Do not factory reset the modem as the first fix.

Before resetting:

  • Confirm you are connected to the Telstra gateway.
  • Try http://mymodem and http://192.168.0.1.
  • Disable VPN and proxy settings.
  • Try another browser or device.
  • Restart the modem.
  • Check the correct default or custom administrator password.

A factory reset can remove custom settings, including Wi-Fi names, passwords, and other configuration. Record anything you need before resetting, and follow the reset instructions for your exact modem model.

Common Mistakes

  • Using mobile data instead of connecting to the Telstra home network.
  • Assuming every Telstra modem uses Telstra as the password.
  • Using your current Wi-Fi password when the modem expects the original label password.
  • Treating the Wi-Fi password and administrator password as permanently identical.
  • Trying 192.168.1.1 when your Telstra gateway uses 192.168.0.1.
  • Factory resetting before trying the simpler access fixes.

FAQs

What is the Telstra gateway login address?
Use http://mymodem or http://192.168.0.1 from a device connected to your Telstra home network.
What is the default Telstra gateway username?
The default username is admin.
What is the default Telstra Smart Modem password?
For Gen 4 and Gen 3, use the original Wi-Fi password printed on the modem label. For Gen 2 and 1.1, use Telstra.
Why does Telstra not work on my modem?
Your modem may be a Gen 4 or Gen 3 Smart Modem, which uses the original Wi-Fi password from its label. Alternatively, the administrator password may have been changed.
Can I change my Wi-Fi password from the gateway page?
Yes. Sign in, open Wi-Fi Settings, update the Wi-Fi Name and Wi-Fi Security Key, then select Apply.
Is the Telstra Gateway Pro address 192.168.0.1?
No. The Telstra Gateway Pro uses 192.168.15.1, with the default username admin and password telstra.

The Bottom Line

Open http://mymodem or http://192.168.0.1 from your Telstra home network and sign in as admin. Use the original Wi-Fi password for Gen 4 and Gen 3 Smart Modems, Telstra for Gen 2 and 1.1 models, and your custom password if you changed it. If the page will not open, check the connection and disable VPN or proxy settings before restarting the modem.
