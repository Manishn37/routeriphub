Sky Broadband (UK) Gateway Login — 192.168.0.1 Admin Access

If you searched 192.168.0.1 expecting your Sky Broadband hub’s settings page, you have the right address for many Sky hubs. The password depends on the hub model: some older Sky hubs use sky, while newer Sky Broadband Hubs use the Wi-Fi password printed on the hub label.

Open 192.168.0.1 from a device connected to your Sky home network. Sign in with admin and the correct password for your hub.

How to Log In to Your Sky Hub

1. Connect to the Sky home network

Connect your phone, tablet, or computer to the Sky hub’s Wi-Fi network. For a more reliable connection, use an Ethernet cable between your computer and one of the hub’s LAN ports.

Do not use mobile data. The hub settings page is a local interface and must be accessed from the home network.

2. Open the management address

Enter this directly into your browser’s address bar:

192.168.0.1 or https://192.168.0.1

Do not enter the address into a search engine. You need the local hub interface, not a web search result.

3. Accept the HTTPS warning if it appears

If your browser shows a message such as “Your connection is not private,” select Advanced, then choose the option to proceed to 192.168.0.1.

This warning can appear because the hub uses a self-signed certificate for its local HTTPS page. Only proceed if you entered the address yourself and are connected to your own home network.

4. Enter the administrator credentials

Use:

  • Username: admin
  • Password: sky for older Sky hubs, or the Wi-Fi password on the hub label for newer models

If you changed the hub administrator password previously, use your current custom password instead.

5. Open the settings you need

Once signed in, open the section related to your task. Common options include Wi-Fi settings, connected devices, security settings, and advanced hub configuration.

Change Your Sky Wi-Fi Name and Password

To change the wireless network details:

  1. Sign in to the hub at 192.168.0.1.
  2. Open Wireless, WiFi, or Wireless Settings.
  3. Find the Wi-Fi network name and password fields.
  4. Enter your preferred Wi-Fi name and password.
  5. Select Apply or Save.

Changing the Wi-Fi password disconnects devices using the old password. Reconnect them using the new password.

Admin Password vs. Wi-Fi Password

The hub administrator password opens the Sky hub’s settings page. The Wi-Fi password connects devices to the wireless network.

On newer Sky Broadband Hubs, the default administrator password may be the same as the original Wi-Fi password. That does not mean they remain the same after either password is changed.

If you changed the Wi-Fi password but not the administrator password, use the original hub-label password to sign in. If you changed the administrator password, use that custom password instead.

If 192.168.0.1 Will Not Open

1. Confirm the connection

Make sure your device is connected to the correct Sky hub. If you have a mesh system, extender, powerline adapter, or separate router, you may be connected to a different device.

Use a direct Ethernet connection to the Sky hub when possible. This removes Wi-Fi signal issues from the troubleshooting process.

2. Check the address carefully

Use:

http://192.168.0.1 or https://192.168.0.1

Avoid incorrect entries such as:

  • 192.168.o.1
  • 192.168.0.l
  • 192.168.0.1.com
  • 192.168.0.1 router login

Enter the address directly into the browser’s address bar rather than a search engine.

3. Try the secure address

If the standard address does not load, use:

https://192.168.0.1

Sky’s hub-settings guidance specifies using https rather than http for the hub address.

4. Disable VPN or proxy temporarily

A VPN, proxy, or privacy-focused browser setting can interfere with access to a local hub address. Disconnect the VPN and disable proxy settings, then try again.

5. Try another browser or device

Try Chrome, Firefox, Edge, or Safari. If one browser fails, test the page from another phone, tablet, or computer connected to the same Sky network.

6. Restart the hub

Turn the hub off, wait about 30 seconds, then turn it back on. Wait for the lights to stabilize, reconnect your device, and try 192.168.0.1 again.

A restart preserves your hub settings. Do not confuse it with a factory reset.

If the Password Is Rejected

Check the hub model

The default password changes by hub type:

What you have Password to try
Older Sky Hub sky
Sky Q Hub sky
Newer Sky Broadband Hub Wi-Fi password on the hub label
Sky Router 4 Wi-Fi password on the hub label
Previously configured hub Your custom administrator password

Check the correct password field

Do not automatically enter your current Wi-Fi password. For newer hubs, the default administrator password is the original Wi-Fi password printed on the hub label—not necessarily the password currently used to connect devices.

Check whether the password was changed

If you or someone else changed the administrator password, the original label password will no longer work. Use the current custom password instead.

When to Factory Reset the Hub

Do not factory reset the hub as the first fix.

Before resetting:

  • Confirm you are connected to the Sky hub.
  • Try http://192.168.0.1 and https://192.168.0.1.
  • Disable VPN and proxy settings.
  • Try another browser or device.
  • Restart the hub.
  • Check the correct default or custom administrator password.

A factory reset can remove custom settings, including Wi-Fi names, passwords, and other configuration. Record anything you need before resetting, and follow the reset instructions for your exact hub model.

Common Mistakes

  • Using mobile data instead of connecting to the Sky home network.
  • Assuming every Sky hub uses sky as the password.
  • Using your current Wi-Fi password when the hub expects the original label password.
  • Treating the Wi-Fi password and administrator password as permanently identical.
  • Trying 192.168.1.1 when your Sky hub uses 192.168.0.1.
  • Factory resetting before trying the simpler access fixes.

FAQs

What is the Sky Broadband hub login address?
The standard address is 192.168.0.1. You can also use https://192.168.0.1.
What is the default Sky hub username?
The default username is admin.
What is the default Sky hub password?
For older Sky hubs, use sky. For newer Sky Broadband Hubs, use the Wi-Fi password printed on the hub label.
Why does sky not work on my hub?
Your hub may be a newer model that uses the Wi-Fi password on its label instead. Alternatively, the administrator password may have been changed.
Can I change my Wi-Fi password from the hub page?
Yes. Sign in, open Wireless or WiFi, update the Wi-Fi name and password, then select Apply or Save.
Is the Sky hub admin password the same as the Wi-Fi password?
On newer Sky hubs, the default administrator password may be the original Wi-Fi password. They are separate settings and can be changed independently.

The Bottom Line

Open 192.168.0.1 from your Sky home network and sign in as admin. Use sky for older Sky hubs, the Wi-Fi password on the hub label for newer models, and your custom password if you changed it. If the page will not open, check the connection and disable VPN or proxy settings before restarting the hub.
