Quick Integration Snippets

Incorporate RouterIPHub's live datasets directly into your network engineering scripts:

Python 3 (Fetch & Filter by Brand) 
import urllib.request
import json

url = 'https://routeriphub.com/data/routers.json'
with urllib.request.urlopen(url) as res:
    routers = json.loads(res.read().decode())

# Filter for ASUS models
asus_routers = [r for r in routers if 'asus' in r['brand'].lower()]
for r in asus_routers:
    print(f"{r['model']} -> IP: {r['ip']} | Default Pass: {r['password']}")
cURL / JQ Terminal Pipe 
# Fetch all Netgear credentials via terminal:
curl -s https://routeriphub.com/data/routers.json | jq '.[] | select(.brand == "Netgear") | {model, ip, password}'
