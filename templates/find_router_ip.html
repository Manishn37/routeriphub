How to Find Your Router IP Address on Any Device

Quick Command Summary

To find your router IP: on Windows, run ipconfig in CMD and check Default Gateway. On macOS, run route -n get default | grep gateway in Terminal. On iOS, tap Settings > Wi-Fi > (i) icon > Router. On Android, view Network Details > Gateway.

1. Find Router IP on Windows 11 & Windows 10

Windows refers to your router's IP as the Default Gateway.

Method A: Via Command Prompt (Fastest)

  1. Press Win + R, type cmd, and press Enter.
  2. Type the following command and hit Enter: 
    ipconfig
  3. Scroll to your active connection (e.g. Wireless LAN adapter Wi-Fi or Ethernet adapter).
  4. Look for the line that reads Default Gateway (e.g., 192.168.1.1 or 192.168.0.1).

Method B: Via PowerShell 1-Liner

Get-NetRoute -DestinationPrefix '0.0.0.0/0' | Select-Object -ExpandProperty NextHop

2. Find Router IP on macOS (Sonoma, Sequoia, Ventura)

Method A: Via Terminal

  1. Open Terminal by pressing Cmd + Space, typing Terminal, and hitting Enter.
  2. Execute this command: 
    route -n get default | grep gateway
  3. Your terminal will output: gateway: 192.168.1.1 (or your local subnet gateway).

Method B: Via System Settings

  1. Click the Apple Logo in the top-left corner > System Settings.
  2. Select Wi-Fi in the sidebar.
  3. Click the Details... button next to your connected network.
  4. Select the TCP/IP tab. Read the IP next to Router.

3. Find Router IP on iPhone and iPad (iOS)

  1. Open the Settings app on your iPhone or iPad.
  2. Tap Wi-Fi.
  3. Ensure you are connected to the network, then tap the blue (i) info icon to the right of the network name.
  4. Scroll down to the IPv4 Address section.
  5. The address shown next to Router is your gateway IP.

4. Find Router IP on Android

  1. Open Settings > Network & Internet (or Connections).
  2. Tap Wi-Fi or Internet.
  3. Tap the gear icon next to your active network name.
  4. Scroll down or expand Advanced. Locate the Gateway entry.
  5. Tip: If the gateway field is not displayed, tap the pencil edit icon, switch IP Settings from DHCP to Static, and note the pre-filled Gateway address.

5. Find Router IP on Linux

Open a terminal window and run either of the following commands:

ip route show default | awk '{print $3}'
